# SWILL Project - Полное руководство по сборке

## Требования
- **Visual Studio 2022** (с компонентом "Desktop development with C++")
- **Windows SDK 10.0**
- **Интернет** (для загрузки MinHook через setup.bat)

## Шаг 1: Подготовка проекта

### 1.1 Запустите setup.bat
```
cd SWILL_Project
setup.bat
```
Этот скрипт автоматически загрузит библиотеку MinHook v1.3.3 и разместит её в папке `3rdparty/MinHook/`.

### 1.2 Проверьте структуру проекта
```
SWILL_Project/
├── 3rdparty/MinHook/
│   ├── include/MinHook.h
│   └── lib.x86/MinHook.lib
├── SWILL_Loader/
│   ├── Injector.hpp
│   ├── Injector.cpp
│   ├── Main.cpp
│   ├── Resource.rc
│   └── SWILL_Loader.vcxproj
├── SWILL_Payload/
│   ├── Memory.hpp
│   ├── Memory.cpp
│   ├── Hooks.hpp
│   ├── Hooks.cpp
│   ├── Core.cpp
│   ├── dllmain.cpp
│   └── SWILL_Payload.vcxproj
├── SWILL_Shared/

├── bin/

```

## Шаг 2: Сборка DLL (SWILL_Payload)

### 2.1 Откройте решение
Откройте файл `SWILL_Project.sln` в Visual Studio 2022.

### 2.2 Настройте конфигурацию
- Выберите конфигурацию: **Release**
- Выберите платформу: **Win32** (x86)

### 2.3 Соберите проект SWILL_Payload
1. В обозревателе решений щелкните правой кнопкой мыши на **SWILL_Payload**
2. Выберите **"Build"** (или нажмите Ctrl+Shift+B)

### 2.4 Скопируйте DLL
После успешной сборки файл `SwillPayload.dll` появится в папке `bin/`.

**ВАЖНО:** Переименуйте его в `swill_payload.bin` и поместите в папку `SWILL_Loader/`:
```
copy bin\SwillPayload.dll SWILL_Loader\swill_payload.bin
```

## Шаг 3: Сборка инжектора (SWILL_Loader)

### 3.1 Соберите проект SWILL_Loader
1. В обозревателе решений щелкните правой кнопкой мыши на **SWILL_Loader**
2. Выберите **"Build"**

### 3.2 Готово!
Файл `SWILL_Loader.exe` появится в папке `bin/`.

## Шаг 4: Использование

### 4.1 Запустите GTA San Andreas с MTA
Убедитесь, что процесс `gta_sa.exe` запущен.

### 4.2 Запустите инжектор
Запустите `bin/SWILL_Loader.exe` от имени администратора.

Инжектор:
1. Найдет процесс `gta_sa.exe`
2. Внедрит DLL через LoadLibraryW
3. DLL автоматически установит хуки на CIdArray::PopUniqueId

### 4.3 Проверьте логи
- `swill_injector.log` - лог инжектора
- `swill_payload.log` - лог DLL внутри процесса игры

## Устранение неполадок

### Ошибка: "No DLL resource found"
**Решение:** Вы не выполнили Шаг 2.4. Убедитесь, что файл `swill_payload.bin` существует в папке `SWILL_Loader/`.

### Ошибка компиляции: "Cannot find MinHook.h"
**Решение:** Запустите `setup.bat` еще раз или скачайте MinHook вручную с https://github.com/TsudaKageyu/minhook/releases

### Ошибка линковки: "Cannot find MinHook.lib"
**Решение:** Убедитесь, что файл `3rdparty/MinHook/lib.x86/MinHook.lib` существует.

### Инъекция не работает
**Решение:** 
1. Запустите инжектор от имени администратора
2. Убедитесь, что антивирус не блокирует инъекцию
3. Проверьте логи на наличие ошибок

## Технические детали

### Почему малый вес файлов?
- Проект не включает тяжелые зависимости (ImGui, DirectX SDK)
- Минимальный набор функций для стабильной работы
- Библиотеки загружаются отдельно через setup.bat

### Работают ли MinHook хуки?
**Да!** Хуки полностью функциональны:
- Перехват CIdArray::PopUniqueId через __fastcall
- Защита от краша при пустом ID стеке
- SEH обработка исключений
- Потокобезопасные атомарные операции

### Где GUI меню?
GUI на базе Dear ImGui **не включен** в текущую версию по следующим причинам:
1. Требует подключения DirectX 9 SDK
2. Значительно увеличит размер проекта
3. Нужен для продвинутого использования, но не обязателен для базовой функциональности

Если вам нужен GUI, добавьте файлы ImGui в папку `3rdparty/` и подключите их в проект.

## Архитектурные особенности

### Исправленные критические ошибки:
1. **Соглашение о вызовах:** __fastcall для эмуляции __thiscall (x86)
2. **Защита памяти:** VirtualQuery проверка перед чтением
3. **RAII:** HandleGuard для автоматического закрытия дескрипторов
4. **Потокобезопасность:** std::atomic для глобальных переменных
5. **Nullptr проверки:** Перед вызовом оригинальных функций

### Безопасная выгрузка:
При DLL_PROCESS_DETACH все хуки автоматически снимаются, предотвращая краш игры.
